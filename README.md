Slope Lab
A practice app for Algebra 1 slope. Get 20 correct answers to fill the game bank, then play a 7-minute game (Snake, Slope Memory, or Whack-a-Slope).

Everything is in index.html. No install or build step is needed.

Publish on GitHub Pages
Create a new public repository on GitHub, for example slope-lab.
Upload index.html and README.md to it.
Go to Settings > Pages, set Source to "Deploy from a branch", choose main and / (root), and save.
After about a minute, the site is live at https://YOUR-USERNAME.github.io/slope-lab/
